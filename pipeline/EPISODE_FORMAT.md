# Формат эпизода (episodes/YYYY-MM-DD.json)

Сюжет всегда один: «миссия» — плохой запрос → провал → один приём → ИИ уточняет → результат → миссия выполнена → шапка профиля.

| Поле | Что это | Лимит |
|---|---|---|
| lines | 9 строк `[сцена, субтитр, текст для озвучки]`, сцены строго по порядку: hook, s1, fail, toggle, type, q, s3, win, cta | субтитр ≤ 12 слов; `*слово*` — выделение; `ПИП!` в субтитре = `[пип]` в озвучке |
| mission | 2 строки под «МИССИЯ:» | ≤ 18 символов каждая |
| bad_prompt | обычный запрос | ≤ 40 символов |
| bad_answer | водянистый ответ ИИ | ≤ 110 символов |
| fail_sub / win_sub / final_sub | подписи под баннерами, формат `--- текст ---` | ≤ 30 символов |
| toggle | `[слева, справа, подпись]` | 1 слово, 1 слово, ≤ 30 символов |
| good_prompt | ДОЛЖЕН начинаться с bad_prompt + приём (приём подсвечивается) | ≤ 110 символов |
| q_user | короткий хвост промпта с «...» | ≤ 45 символов |
| q_replies | 3 вопроса/реплики ИИ | ≤ 30 символов каждая |
| q_stamp | штамп одним словом | ≤ 10 символов |
| result_title / result_rows | заголовок окна и 4 пункта результата | ≤ 30 символов на пункт |
| final_rows | 3 строки `[заголовок, подзаголовок, тег, выделить?]` | ≤ 22 / 30 / 12 символов |
| caption / tiktok_title / youtube_title | тексты публикации | без ссылок; YouTube-заголовок с `#shorts` |
